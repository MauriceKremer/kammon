What a script can do

A script defines on_group_text(message). KAM runs it for every text it hears on the channels the script reacts to.

Field of messageMeaning
channelNormalised name such as #emmen
senderSender name
bodyMessage text
timestamp_unixSender's timestamp
hop_count, hop_stationsHow far it travelled and the one-byte path hashes
has_rx_meta, snr_quarter_db, rssi_dbmSignal data; SNR is in quarter dB (divide by 4)
time_drift_secondsDifference between sender and KAM clocks

reply(channel, text) queues a reply. That is all a script can do: it cannot reach the radio, the files or the network.

The dry run uses KAM's own engine and the same timeout rules, but it cannot reproduce load. A test captures at most 16 replies or 4096 bytes.
